# 多机器同步

仓库地址：https://github.com/lywcoder/dotfiles 。Windows、WSL Ubuntu/Fedora/Arch，以及 Linux 本机和服务器各自保留本地克隆；Linux 克隆放在 Linux 文件系统内。
符号链接只连接当前系统内的路径，不会在两个克隆或两台机器之间传播更改。

修改配置后，先审核差异和未跟踪文件，确认没有密钥，再选择性暂存、提交、推送。不要盲目把整个 HOME 加入版本控制。
其他机器执行 `git pull --ff-only`，然后重开相关程序；新增入口或依赖时重新运行安装脚本。
只 push 不会自动更新其他工作目录；bootstrap 遇到已有克隆也不会自动 pull、reset 或丢弃本地更改。

有未提交改动时先处理，不要强制重置。已提交但不同步的历史应人工处理；不要将首次接入用的 reset 当作日常同步方式。
仓库旧审计文件描述的是建库时的状态，不代表当前 Git 状态。当前请以 `git status`、`git remote -v` 和提交历史为准。

初始化新机器以及旧的无提交镜像接入前，请先检查目录与历史。新的克隆使用 [安装指南](installation.md)。旧服务器若没有共同历史，不要直接在原目录上重新 clone 或强制覆盖；先备份、审核，再迁移到正常克隆。

安装依赖和插件并不通过 Git 传输软件程序。脚本保存安装逻辑；每台机器执行一次下载。Starship 主题与机器私有覆盖默认独立，详见安装指南。
