# 首次 Windows/WSL 链接迁移与恢复（历史记录）

本次链接只覆盖明确列出的 9 份文件；不链接目录，不操作现有备份或其他用户。

迁移前对源文件计算指纹，进行秘密与语法检查。Windows 原件移动到仓库外的本机备份目录；Ubuntu 原件移动到本用户的仓库外备份目录（目录权限 700）。再在原位置建立文件符号链接。

迁移操作会再次核对源文件指纹，遇到文件变化、已有链接、目标缺失或备份冲突便停止。失败时按已完成记录回滚，避免留下半套配置。Windows 创建链接需要管理员权限或系统已允许无特权创建链接；此次不启用开发者模式或修改持久执行策略。

恢复应逐个文件进行：先确认原路径仍是本次创建且指向预期目标的符号链接，删除该链接，再将对应原件从备份移回。不要递归删除目录，不要覆盖迁移后新建的普通文件。先保存迁移后的必要修改，再恢复。

旧 E 盘仓库不会自动更新。C 盘仓库是新的工作目录；没有自动连接旧仓库或 GitHub。

以后修改后检查 Git 状态、文件差异、符号链接状态，再决定提交。不要自动推送或把所有文件未经审核一并提交。真实凭据通过仓库外文件或凭据工具注入。
